CharacterDS(skill for chatGPT) 是一套專注於「角色深度 DS」的模組化技能，核心目標不是只做一張角色設定板，而是讓角色從靜態設定一路延伸到動態展示，形成完整、可辨識、可持續發展的角色資產。
它以角色身份一致性為核心，支援 Character Sheet、Identity Lock、Turnaround、表情、姿態、服裝、材質與細節設定，並透過模組化版面系統維持整潔、美感與清楚的視覺層級。即使局部模組替換、增減或重排，整體仍能保持一致的設計語言；當使用者沒有指定唯一版型時，也可主動提出三組具有實質差異的搭配方案。
在動態展示方面，CharacterDS 可將靜態設定延伸為人物介紹蒙太奇、身份揭示、材質展示、換裝、情緒建立、雙角色交叉展示等多種變體。動態系統以 Motion、Shot、Reveal、Narrative 等模組自由組裝，而不是依賴單一固定 Prompt，因此能持續產生新的展示形式。
針對多人展示常見的角色污染與資產漂移，CharacterDS 會區分角色、服裝、武器、配件與狀態歸屬，並分開管理動作、節奏、鏡頭方向與身份資產的跨鏡繼承。節奏可以接棒，但角色資產不能串錯。同時透過動作變異控制，降低鏡像動作、重複運鏡與機械式交替造成的視覺疲勞。
系統也會在組裝 Prompt 時整理規則層級、移除無效重複提示，並將靜態 DS 中的代表性表情、服裝、材質與標誌細節轉譯為動態展示節點，讓動靜配套真正建立在同一角色核心上。
CharacterDS 的定位很單純：把角色做深、做穩、做得能被真正展示。它不負責場景、道具或整體影片流程，而是專注於角色本身，讓靜態設定與動態表演共享同一身份核心，最終形成更立體、更可信、也更具有延展性的角色展示系統。
